# СтройРасчёт

Строительные калькуляторы, тоннаж металлопроката, сметы и разбор проектной документации — прямо в браузере.
Данные хранятся у пользователя, документы никуда не загружаются.

## Возможности

**19 калькуляторов** — каждый выдаёт материалы и работы, которые одной кнопкой уходят в смету:

| Раздел | Калькуляторы |
| --- | --- |
| Металл и тоннаж | Металлопрокат (лист, круг, квадрат, шестигранник, полоса, трубы, уголок, швеллер, двутавр, арматура по ГОСТ) со спецификацией и итоговым тоннажем; забор из профнастила |
| Фундамент и бетон | Бетон (лента, плита, столбы, состав замеса, миксеры, опалубка); арматура плиты и ленты |
| Стены | Кирпич и блоки; гипсокартон (перегородки, облицовка, потолки); утеплитель с теплотехническим подбором толщины |
| Отделка и полы | Стяжка и наливной пол; штукатурка и шпаклёвка; краска; обои с раппортом; плитка с клеем и затиркой; ламинат, паркет, линолеум и плинтус |
| Кровля | 1-, 2- и 4-скатные крыши: площадь, покрытие, коньки, мембрана, обрешётка, стропила |
| Земляные и сыпучие | Котлован и траншея с откосами и разрыхлением; тоннаж песка, щебня, ПГС и рейсы самосвалов |
| Дерево и прочее | Пиломатериалы (кубатура, штук в кубе, масса); лестница по формуле Блонделя; конвертер единиц (МПа ↔ кгс/см², кН ↔ тс…) |

**Документы** — перетащите файлы, папку или архив:

- архивы ZIP, RAR, 7Z, TAR, GZ любой вложенности; русские имена из архивов Windows (CP866) читаются корректно;
- просмотр PDF, Excel (XLSX/XLS/ODS/CSV), Word (DOCX), ODT, изображений, текста и чертежей DXF;
- автоматический поиск таблиц смет и спецификаций (наименование, ед., количество, цена, сумма, масса), в т.ч. в PDF;
- распознавание профилей металла («Уголок 50х5», «Швеллер 10П», «Двутавр 20Б1», «Ø12 А500С», «Гн□100х4», «Лист 10») и расчёт тоннажа по ГОСТ;
- полнотекстовый поиск по всем документам пакета;
- импорт найденных позиций в новую или существующую смету, металла — в спецификацию.

**Сметы** — разделы и позиции (материалы, работы, механизмы, доставка), наценка, накладные, сметная прибыль, непредвиденные, скидка, НДС сверху или в т.ч. (по умолчанию 16%), сводка по массе. Выгрузка в Excel с живыми формулами, CSV, печать и PDF (смета или КП с реквизитами), JSON-копии.

**Справочник цен** — ориентировочные цены материалов и работ; свои цены и позиции сохраняются и подставляются во все расчёты.

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты формул, смет и разбора документов
npm run build      # статическая сборка в dist/
```

Сборка — статические файлы с относительными путями и hash-роутингом: её можно положить на любой хостинг
(GitHub Pages, S3, nginx, просто папку). Для GitHub Pages есть готовый workflow
`.github/workflows/deploy.yml` — включите *Settings → Pages → Source: GitHub Actions*.

## Архитектура

```
src/
  calculators/        декларативные калькуляторы: поля формы + чистая функция compute()
    defs/             определения по разделам; registry.ts — каталог и поиск
  data/               справочные данные: ГОСТ-таблицы металла, плотности, грунты, цены
  lib/                чистая логика: смета и итоги, масса металла, распознавание профилей, экспорт
  docs/               документы: распаковка (zip/tar/gz/7z-wasm), кодировки, извлечение таблиц, анализ
  store/              состояние (zustand + localStorage): сметы, цены, настройки, спецификация, документы
  components/, pages/ интерфейс (React 19, Tailwind CSS 4)
```

- **Калькулятор = данные.** Каждый калькулятор описан схемой полей и функцией `compute(values) → { metrics, lines }`.
  Форма, результат, цены, «В смету», ссылка «Поделиться» и запоминание ввода — общие для всех.
  Новый калькулятор — один файл в `src/calculators/defs` и строка в `registry.ts`.
- **Строки результата ссылаются на справочник цен** (`priceKey` × `priceFactor`, например ₸/кг × мешок 25 кг),
  поэтому цена, изменённая один раз, используется везде.
- **Расчёты выполняются на клиенте** — мгновенно и без сети (удобно на объекте); тяжёлые библиотеки
  (pdf.js, SheetJS, mammoth, 7-Zip WASM) загружаются только при открытии документов.
- Формулы и разбор документов покрыты тестами (`*.test.ts`): табличные значения ГОСТ, итоги сметы с НДС,
  распаковка вложенных архивов, CP866/CP1251, распознавание профилей и таблиц.

SheetJS подключён из npm-зеркала `@e965/xlsx` (сборка официального 0.20.3 с исправленными уязвимостями
0.18.5); версия зафиксирована.

## Дальнейшее развитие

1. **Сервер на Go** — аккаунты, синхронизация смет между устройствами, общий справочник цен компании,
   совместная работа. Модель данных (`lib/estimate.ts`) уже отделена от интерфейса и сериализуется в JSON.
2. **OCR сканов** (PDF без текстового слоя, фото накладных) и **конвертация DWG** — на сервере.
3. **ИИ-разбор документов** — свободный текст ТЗ и ведомостей → позиции сметы.
4. Импорт/экспорт форматов сметных программ (АРПС 1.10, XML Гранд-Сметы), базы ГЭСН/ФЕР.
5. PWA: установка на телефон и полная работа офлайн.
6. Шаблоны смет (ремонт квартиры, фундамент, кровля), история изменений и версии смет.
